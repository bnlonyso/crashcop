# 🔮 crashcop

**crashcop** — современный, быстрый клиент электронного дневника и умный симулятор оценок и процентов для учащихся НИШ.

![crashcop](public/apple-touch-icon.png)

## ✨ Особенности

- 🧮 **Умный симулятор процентов и баллов**: Прогнозируйте итоговый процент за четверть и год. Узнайте, сколько баллов нужно набрать на СОЧ для получения заветной «5» или «4».
- 🧪 **Гипотетический режим для каждого предмета**: Меняйте баллы за СОР и СОЧ в режиме реального времени или добавляйте новые гипотетические суммативки.
- 🎨 **Современный Purple UI**: Тёмная и светлая тема в фиолетовых оттенках с плавными анимациями.
- 📊 **Табель и симулятор GPA**: Просмотр четвертных, полугодовых и годовых результатов с возможностью прогнозирования GPA.
- ⚡ **Быстродействие**: Построен на базе Next.js 14, Tailwind CSS и TanStack Query.

## 🚀 Быстрый старт

```bash
# Клонирование репозитория
git clone https://github.com/bnlonyso/crashcop.git
cd crashcop

# Установка зависимостей
pnpm install # или npm install

# Запуск в режиме разработки
pnpm dev # или npm run dev
```
